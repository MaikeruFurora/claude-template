# \# Architecture

# 

# \## Backend (Laravel)

# \- Controllers handle requests only

# \- Services contain business logic

# \- Models handle database

# 

# \## Frontend (React)

# \- Pages = screens

# \- Components = reusable UI

# \- Services = API calls

# \- Store = global state

# 

# \## API Flow

# React → Laravel API → Service → Database → Response
