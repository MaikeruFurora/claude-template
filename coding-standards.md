# \# Coding Standards

# 

# \## Backend

# \- Use Service layer

# \- Validate all requests

# \- Return JSON only

# 

# \## Frontend

# \- Use reusable components

# \- Keep API logic in services

# \- Use Redux for global state

# 

# \## Naming

# \- camelCase (JS)

# \- PascalCase (Components)

# \- snake\_case (DB)
